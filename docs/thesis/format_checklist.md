# 毕业论文格式检查表

依据：`docs/school-requirements/能源工程学院本科生毕业论文工作细则-2026届.md`

本文档作为后续写作与定稿前的自查表使用。每完成一章或一次大修后，应回到本文件检查是否满足学院格式要求。

## 1. 成册顺序

- [ ] 封面
- [ ] 诚信承诺书
- [ ] 致谢
- [ ] 中文摘要与关键词
- [ ] 英文摘要与关键词
- [ ] 目录
- [ ] 论文正文
- [ ] 参考文献
- [ ] 作者简介（可省略）
- [ ] 本科生毕业论文（设计）任务书
- [ ] 毕业论文（设计）考核表

## 2. 摘要与关键词

- [ ] 中文摘要控制在 300-600 字左右
- [ ] 英文摘要约 300 个实词
- [ ] 中英文摘要内容对应
- [ ] 摘要应包含研究目的、方法、结果和结论
- [ ] 中文关键词 3-8 个
- [ ] 英文关键词与中文关键词对应，实词首字母大写

## 3. 正文章节结构

本文采用用户确认的五章结构：

- [ ] 1 绪论
- [ ] 2 对中算法
- [ ] 3 仿真系统研究与对中算法测试
- [ ] 4 实验验证
- [ ] 5 总结

正文写作要求：

- [ ] 章节编号采用 `1`、`1.1`、`1.1.1` 层级
- [ ] 每章开头说明本章研究内容
- [ ] 每章结尾设置“本章小结”
- [ ] 正文术语前后一致，如“对中”“轴系不对中”“LD”“PSD”“M侧”“S侧”
- [ ] 英文缩写首次出现时给出中文含义和英文全称

## 4. 图格式

- [ ] 图号按章编号，如 `图3.1`
- [ ] 图题置于图下方居中
- [ ] 图题格式为“图号 + 空格 + 图名”，图名后不加标点
- [ ] 图必须先在正文中引出，再放置图片
- [ ] 坐标图应标注变量、符号和单位
- [ ] 图中字号、中文、英文和数字格式后续在 Word 排版阶段统一
- [ ] 每张图应具有自明性，图名和图注能说明图意

## 5. 表格式

- [ ] 表号按章编号，如 `表3.1`
- [ ] 表题置于表上方居中
- [ ] 表题格式为“表号 + 空格 + 表名”，表名后不加标点
- [ ] 表格必须先在正文中引出，再放置表格
- [ ] 表格优先采用三线表
- [ ] 表内数字上下对齐
- [ ] 表中变量、缩略词和单位与正文一致

## 6. 公式格式

- [ ] 公式按章编号，如（2.1）、（3.1）
- [ ] 正文引用公式时写作“见式（2.1）”
- [ ] 公式中的变量首次出现后应说明物理意义和单位
- [ ] 长公式换行时在运算符后断开
- [ ] Markdown 草稿阶段优先使用 `$$ ... $$` 块公式，便于公式插件渲染
- [ ] Word 定稿阶段再统一公式编号位置和字体

## 7. 参考文献

- [ ] 参考文献不少于 10 篇
- [ ] 外文文献不少于 3 篇
- [ ] 采用顺序编码制
- [ ] 正文引用编号与文后参考文献编号一致
- [ ] 引用标注放在相关正文处，不放在句号后
- [ ] 格式遵照 GB/T 7714-2015
- [ ] 中文文献和英文文献在最终 Word 排版中分别检查字体

## 8. 后续 Skill 使用检查

- [ ] `sci-extract`：已完成已有材料与代码提取
- [ ] `sci-search`：已补充第1章、第2章文献依据
- [ ] `sci-zotero`：已统一参考文献条目
- [ ] `sci-review`：已逐章审阅语言、逻辑和格式
- [ ] `sci-figure`：已统一图题、图号和图注
